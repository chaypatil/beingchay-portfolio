Work/Ticombo

Live events, listed automatically

Content Marketer, Oct 2023 to Feb 2025. Ticombo is a ticket resale marketplace. Besides running content, I set up automations that watched live event sites and listed new events for resellers without anyone copying them over.

01/The problem

Resellers can only sell what's already on the marketplace.

New events go live on venue calendars, promoter pages and box offices all the time. Copying each one over by hand is slow, and every hour an event isn't listed is an hour resellers can't sell it.
